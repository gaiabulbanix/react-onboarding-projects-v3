# CSS/UI/UX Guidelines v2.0

## Status
Keep this document. It is still useful, but update it to reflect React + Tailwind usage.

## Current Principles
- Consistency > visual flair
- Reuse patterns before creating new abstractions
- Build feature-first, design-system second
- Mobile-friendly layouts by default
- Clear hierarchy: Header → Content → Actions

## Approved UI Patterns
- Panel
- Button (variants + sizes)
- FormInput
- List → Item pattern
- Empty states
- Inline edit mode

## Avoid
- Premature design systems
- Animation rabbit holes
- Excessive abstraction
- Styling before functionality
